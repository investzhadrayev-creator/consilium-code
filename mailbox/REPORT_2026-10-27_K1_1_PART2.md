## Определения

- **NOT_APPLICABLE** — показатель математически не определён: CAGR/рост при неположительной базе (или конце окна), FCF/NI при NI ≤ 0, маржа при выручке ≤ 0 (в т.ч. медиана за 5 ФГ, если дыра из-за выручки ≤ 0). Не «заполнено» и не «пробел».
- **OUT_OF_SCOPE_FORM** — в списке подач адаптера нет формы 10-K с filing_date ≤ as_of (20-F/40-F, IFRS, ещё нет первого 10-K). Если список подач прочитать не удалось — имя НЕ объявляется вне scope (остаётся пробел).
- **(А)** = заполнено / все поля всех имён.
- **(Б)** = заполнено / применимые поля имён в scope (scope = имя не OUT_OF_SCOPE_FORM; применимое = не NOT_APPLICABLE). Пробел по нашей вине (в т.ч. недоступные цены) остаётся в знаменателе. Пустой знаменатель печатается «н/д», не 0 и не 100%.
- Сплиты: подтверждённый сплит (`confirmed_splits` адаптера) → ряд акций пересчитывается на пост-сплитовую базу с пометкой `split_adjusted` и коэффициентом. База строки определяется датой подачи её accession относительно окна сплита (pre = max earliest_filed, post = min latest_filed): подана ≤ pre → до сплита (×factor), ≥ post → уже после, между или без даты → отказ `SPLIT_IN_WINDOW` (база недоказуема), не угадывание.
