# РЕШЕНИЕ ПО АРБИТРАЖУ ПИЛОТОВ: четыре вердикта

## В1 = ВАРИАНТ A (позиция ChatGPT; позиция AI Studio отклонена)

Пилот INTC-2022-01-28 остаётся **FAILED** по букве собственной пре-регистрации.
STOP BUILD исполняется и не переписывается пост-фактум. Основание: цена
прецедента «санкция пересматривается после неудобного результата» выше цены
дней задержки; способность неудобного результата реально останавливать
работу — подтверждённая этим провалом ценность системы.

**Семантика STOP BUILD (по прочтению арбитра, принята):**
- РАЗРЕШЕНО: postmortem; проектирование и калибровка сторожа; новые
  пре-регистрации; новый пилот; **счёт проверки №1** (исполнение протокола,
  замороженного до событий, — не стройка).
- ЗАПРЕЩЕНО до нового затвора: боевой NDX-рейтинг; внедрение CASH_DECAY
  в любом виде; использование Intel как теста или доказательства; любые
  новые боевые функции.

**Правило масштаба санкций (действует только вперёд):** провал компонентного
пилота → заморозка компонента и зависимого денежного пути; провал
архитектурного затвора → глобальный STOP BUILD.

## В2 = ПЕРЕПРОЕКТИРОВАНИЕ СТОРОЖА (единогласно)

Архитектура «жёсткое И двух бинарных порогов» отвергнута. Новая:
- FCF/NI — главный сигнал итога; OCF/NI и capex/OCF — каналы механизма,
  ни один не является обязательными воротами;
- градации RED / AMBER / OK / NOT_APPLICABLE; severe-случаи по ИЛИ
  (NI>0 при FCF<0 — красный сам по себе);
- калибровка на отдельном корпусе по стандарту ChatGPT: 100–150 фирм-лет,
  ≥30 компаний, ≥25 настоящих распадов разных механизмов, деление
  по компаниям (2/3 калибровка, 1/3 holdout), метка исхода фиксируется
  до калибровки, оптимизация полноты при заранее выбранном бюджете ложных
  тревог;
- Intel — сожжённый кейс: только учебный пример, никогда тест;
- IBM FY2014 (кандидат AI Studio) — в калибровочный корпус (выкупной распад);
  Paramount FY2021 — резерв holdout.

## В3 = НОВЫЙ ПИЛОТ: NETFLIX ПОСЛЕ 10-K ЗА FY2019 (позиция ChatGPT)

Механизм распада принципиально иной, чем у Intel: прибыль положительна,
деньги горят в операционном потоке (контент), классический capex-канал
не обязан ничего объяснять; заодно нагружается логика NOT_APPLICABLE
при отрицательном OCF. Пре-регистрация — отдельным документом; до фиксации
порогов финансовые числа среза не открываются (разрешён только
метадата-запрос даты подачи). Пилот сторожа не загрязняет проверку №1:
CASH_DECAY не входит в её замороженный протокол.

## В4 = ВАРИАНТ (б): ДВА МОСТА ПАРАЛЛЕЛЬНО (позиция ChatGPT; срочность AI Studio учтена)

Официальный результат проверки №1 — только по замороженной методике
PREREG_2026-08-06. Параллельно на тех же входах считается полный FCFF/DCF-мост
с пометкой EXPLORATORY — NOT USED FOR TEST #1 VERDICT, с дельтами по каждому
имени. Главный мост для проверки №2 выбирается по измеренной кросс-секционной
карте расхождений и замораживается новой пре-регистрацией до проверки №2.
