# ПРОТОКОЛ ЕЖЕДНЕВНОГО АУДИТА «СКАЗАНО — СДЕЛАНО» v1

Исполнение: tools/daily_audit.py, cron 21:00 Астаны ежедневно.

## Механика v1 (работает со дня закладки)
1. Пакет дня: команды архитектора из несмываемого лога; фактические коммиты
   за 26ч; статусы автоматики; открытые задачи; незакрытые пункты прошлого
   аудита. Пустой день → аудит не проводится.
2. Аудитор дня: чётное число месяца → OpenAI, нечётное → Gemini
   (перекрёстный эффект: каждый видит вчерашний аудит коллеги).
3. Проход 1 — сверка: по каждому заявлению ПОДТВЕРЖДЕНО (факт) или
   РАСХОЖДЕНИЕ (заявлено X, факт Y). Обязательные классы: команда без следа
   исполнения; изменение правил без команды; упавший прогон без доклада.
4. Проход 2 — доследование каждого РАСХОЖДЕНИЯ по сырым доказательствам,
   отмолчаться нельзя: «ПОДТВЕРЖДАЮ НАРУШЕНИЕ + ПРИЧИНА + ПЛАН исправления»
   либо «ОТЗЫВАЮ + почему первое впечатление ошибочно».
5. Вердикт коммитится в journal/audits/ МИНУЯ архитектора; подтверждённое
   нарушение → письмо оператору напрямую; нарушение висит UNRESOLVED
   в каждом последующем аудите до закрытия.
