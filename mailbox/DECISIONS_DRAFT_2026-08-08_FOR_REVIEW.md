## §2. Режим оценки для этого универсума — рейтинг по разрыву роста (ГЛАВНЫЙ ВОПРОС РАУНДА)

Оба рецензента сошлись: классический Грэм-Додд на Nasdaq-100 будет 95% времени
говорить «дорого», а «дешёвыми» называть угасающие бизнесы (value traps).
Оператор согласился: для этого универсума нужен другой режим.

Проект решения: главным выходом системы для Nasdaq-100 становится **обратный
расчёт ожиданий** (reverse-DCF / expectations investing): для каждого имени
решается уравнение «какой рост прибыли на акцию требуется, чтобы оправдать
текущую цену при ставке 12% и терминальном множителе по формуле
min(историческая медиана, payout/(k_exit−g))», и универсум ранжируется
по разрыву:

```
требуемый рост (из цены) − достижимый рост (фактический CAGR прибыли 5 лет)
```

Малый или отрицательный разрыв = рынок просит скромного будущего;
большой = героического. Абсолютные вердикты «покупать/избегать» понижаются
до справочной строки без алертов.

Что уже есть: обратный расчёт реализован и публикуется; известный дефект —
он решает уравнение на бухгалтерской базе даже при FCF-вердикте — принят
к починке до перехода (ваша находка первого аудита).
