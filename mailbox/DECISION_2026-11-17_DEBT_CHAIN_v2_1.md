# DECISION 2026-11-17 — цепочка долга, v2.1: выбор подачи на дату

Основание: разбор SNPS в PR #439 (отчёт `Reports/floor1/REPORT_2026-11-16_IONQ_COVERAGE.md` §3, §4.1), решение архитектора в задаче #440. На 2022-10-31 у SNPS две подачи 10-K: accn 0000883241-22-000017 (filed 2022-12-12; размечены нетекущая часть 20 824 000 и `DebtCurrent` = 0) и accn 0000883241-23-000019 (filed 2023-12-12; только нетекущая часть). Правило v2 берёт более позднюю, неполную, и отбрасывает точку целиком.

## 1. Выбор подачи на дату ФГ
Для даты ФГ среди подач формы 10-K*, раскрывающих на эту дату нетекущую часть долга, берётся самая поздняя по дате подачи из ПОЛНЫХ. Полная = в ней размечены и нетекущая, и текущая часть; либо текущая часть не размечена ни в одной подаче на эту дату (тогда текущая = 0 по v2 §1). Если полной подачи нет — отказ «одна подача нарушена», как прежде. Смешивать части из разных подач по-прежнему нельзя.

## 2. Отказ не теряется
Если точка ряда на любую дату (не только последнюю) отброшена по правилу «одна подача нарушена», то отказ поля, которому эта точка нужна (например, `net_debt_chg_3y`), называет именно эту причину и дату, а не «нет точки».

## 3. Срок
Действует для карточек с as_of ≥ 2026-11-21. Карточки до этой даты не пересчитываются.

## 4. Условие вступления
Код к закону сливается, только если отчёт влияния по всем 34 именам (as_of 2026-11-14, все поля долга: `net_debt_latest`, `net_debt_chg_3y`, `DEBT_FOR_BUYBACKS`) показывает 0 ячеек «число → отказ», а каждая ячейка «число → другое число» перечислена с причиной. Иначе код не сливается, а срок по п. 3 переносится отдельным решением.

## 5. Честная оговорка
Правило введено после того, как дефект был замечен на SNPS (карточка 14.11: `INSUFFICIENT_HISTORY` вместо числа). Обе цифры покрытия ((Б) и (Б) без новых классов) по-прежнему публикуются каждую неделю. Новых классов исключения из знаменателя закон не вводит.

## 6. Не принято
Сравнительный столбец 10-Q для даты конца ФГ (случай IONQ) — не принят; вернуться после решения GO/NO-GO 06.12.
