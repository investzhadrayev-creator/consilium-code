# Автопилот КОД: слияние мостом без оператора

1. **За оператором остаются** (мост по ним всегда отказывает в MERGE; в CODEOWNERS — построчно):
   `.github/`, `CODEOWNERS`, `CLAUDE.md`, `mailbox/DECISION_*`, `mailbox/PREREG_*`, `mailbox/MANDATE_*`
   и контрольная плоскость: `tools/validate_artifacts.py`, `tools/autocommit.py`, `tools/mail_bridge.py`,
   `tools/schedule_guard.py`, `tools/llm_clients.py`, `tools/daily_audit.py`, `tools/monthly_audit.py`,
   `tools/audit_facts.py`, `tools/calibrate_auditor.py`.
2. **Остальной код** (прочие `tools/*`, `CONSILIUM_REPO_*`, тесты) сливается командой моста
   `[CONSILIUM-MERGE] PR#N` только если выполнено ВСЁ: (i) автор PR — claude[bot]; (ii) в теле PR есть
   строка «Тип: КОД» («Тип: ЗАКОН» — отказ); (iii) все check-runs головного коммита завершены и успешны,
   среди них есть тесты (job `suite` из `tests.yml`); нет check-runs или нет тестов — отказ
   «тесты не запускались»; (iv) PR без конфликтов (mergeable); (v) не окно заморозки (п. 3).
   Неизвестное (статус не получен, mergeable=UNKNOWN) — именованный отказ, не «наверное можно».
   Слияние привязано к проверенному головному коммиту (`--match-head-commit`).
   Отказ — комментарий в PR + уведомление ACTION; успех — уведомление INFO «слит PR #N: <заголовок>».
   FILE-команды не меняются (DECISION/PREREG/MANDATE → PR оператору).
3. **Заморозка**: с пятницы 00:00 UTC до воскресенья 08:00 UTC мост не сливает PR, трогающие
   `tools/floor1_card.py`, `tools/panel_axes.py`, `config/` — чтобы не сорвать субботнюю публикацию.
4. **Прозрачность**: каждое автослияние идёт в дневной отчёт строкой «Слит мостом без оператора: <заголовок>»
   (тема squash-коммита начинается с `[CONSILIUM-MERGE]`) и подлежит проверке ежедневным аудитором.
5. **Отмена**: оператор вправе отменить решение одной строкой (новый DECISION, возвращающий `tools/` в CODEOWNERS).

Известные границы: переименование файла из защищённого пути не видно в списке файлов `gh pr view`
(там только новый путь) — страхует ruleset «require code owner review» по CODEOWNERS; `CLAUDE.md`
внутри `CONSILIUM_REPO_*` в список оператора не входит («ровно» по задаче).
