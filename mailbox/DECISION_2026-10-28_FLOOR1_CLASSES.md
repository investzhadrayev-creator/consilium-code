# РЕШЕНИЕ: ДВА КЛАССА НЕПРИМЕНИМОСТИ КАРТОЧКИ ЭТАЖА 1 (с субботы 2026-10-31)

## Почему
После исправления наших ошибок чтения (K1.1, K1.2) покрытие (Б) = 660/735 = 89,8%. Разбор 77 оставшихся пробелов (REPORT K1.2): почти все — показатели, которых у компании нет по природе, а не ошибки чтения: валовая маржа у платёжной сети (MA) и страховщика (OSCR), операционная прибыль у банка (SOFI), маржи у компании без выручки (OKLO), долг у компаний без долговых обязательств в отчётности, 5-летние медианы у компаний с 2-летней публичной историей (RDDT, SHOP). Требовать от них 95% — значит мерить инструмент тем, чего в данных не может быть.

## Классы (по правилу, не по имени; реализация — K1.3)
1. NOT_REPORTED — показатель не представлен компанией: ни один тег цепочки поля (включая все запасные) не имеет ни одного факта в SEC companyfacts ни за последний ФГ карточки, ни за 3 предшествующих. Хоть один факт за эти 4 ФГ — это пробел по нашей вине, не класс.
2. SHORT_HISTORY — окну поля нужно N ФГ (или 52 недели цен), а самый ранний годовой факт выручки (или первая котировка) позже начала окна. Есть ранняя история, но нет конкретной точки — пробел, не класс.

## Правила применения
- Оба класса исключаются из знаменателя (Б), как NOT_APPLICABLE; в числитель не входят. Зависимые флаги — UNDETERMINED, никогда CLEAR (консервативно).
- Карточка каждую неделю показывает И (Б), И «(Б) без новых классов» — влияние этого решения видно всегда.
- Класс не означает ноль: ячейка показывает «не представлено компанией» / «короткая история» с проверенными тегами и датами.

## Честная оговорка (для аудиторов)
Классы вводятся ПОСЛЕ того, как известны цифры (информационный расчёт K1.2: оба класса → (Б) ≈ 97,3%; только «не представлено» → 94,8%; без классов → 89,8%). Защита от подгонки: правило объективное и проверяемое по данным SEC, а не по именам; вводится ДО первой засчитанной недели; «(Б) без новых классов» публикуется рядом; дальнейшие классы — только отдельным решением до субботы применения, задним числом — никогда. Раунд 9 (аудиторы) проверяет обоснованность.

## Альтернатива (если оператор не одобрит)
Без классов (Б) ≈ 90%; пробелы структурные, исправлением кода не закрываются — пункт 1 гейта станет невыполнимым, и понадобится изменение пре-регистрации (хуже, чем класс по правилу сейчас).
