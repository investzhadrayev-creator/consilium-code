# РЕШЕНИЕ: КАК СЧИТАЕТСЯ ПОКРЫТИЕ КАРТОЧКИ ЭТАЖА 1 ДЛЯ ГЕЙТА

## 1. Два числа покрытия (определения из PR #109, без изменений)
- (А) сырое = заполненные поля / все поля всех имён списка наблюдения. Публикуется всегда, справочно.
- (Б) применимое = заполненные поля / применимые поля имён в scope.
 - Scope: имя НЕ OUT_OF_SCOPE_FORM. OUT_OF_SCOPE_FORM = в списке подач SEC на дату карточки нет годовой формы 10-K (20-F/40-F, IFRS или ещё нет первого 10-K). Если список подач не прочитан — имя НЕ объявляется вне scope.
 - Применимое поле: не NOT_APPLICABLE. NOT_APPLICABLE = показатель математически не определён: рост при базе ≤ 0, FCF/NI при NI ≤ 0, маржа при выручке ≤ 0, BUYBACK_EPS при неположительных NI/EPS.
 - Пробел по нашей вине (нет тега, устаревший ряд, отказ адаптера, недоступные цены, короткая история) остаётся в знаменателе (Б).

## 2. Порог гейта
PREREG v2 п. 1 «покрытие ≥ 95% или named limitation» исполняется так: неделя засчитывается, если (Б) субботней карточки ≥ 95%. Классы OUT_OF_SCOPE_FORM и NOT_APPLICABLE — это и есть named limitation по правилу; разрозненные пробелы по именам named limitation НЕ являются.

## 3. Заморозка
Определения п. 1–2 фиксируются ДО первой засчитанной автонедели. Новый класс неприменимости (если понадобится) — только отдельным файлом-решением с обоснованием, одобренным оператором ДО субботы, к которой он применяется; задним числом — никогда. Перенастройка «до прохождения» запрещена (как для экзамена NFLX).

## 4. Денежные средства с ограничением
Если чистый долг посчитан через тег, включающий ограниченные денежные средства, поле помечается cash_includes_restricted, а флаг DEBT_FOR_BUYBACKS по такой точке — UNDETERMINED, не CLEAR.
