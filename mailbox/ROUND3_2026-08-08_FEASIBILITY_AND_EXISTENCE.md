# ЧАСТЬ 1. ИТОГОВАЯ КОНСТРУКЦИЯ ПОСЛЕ ДВУХ РАУНДОВ

Сводка принятого; если ваш пункт понят неверно — скажите.

* **Универсум** — Nasdaq-100 (приоритет оператора «компании первичны, метод
  вторичен» принят открыто); сторож новых участников индекса — в реестре.
* **Режим** — обратный расчёт ожиданий. Главный счёт — **подразумеваемая
  доходность** при нормализованном сценарии против личного порога 12%;
  **разрыв роста** рядом как объяснение (арбитраж ChatGPT). Абсолютные
  вердикты — справочная строка без алертов.
* **Вместо одного «достижимого роста» — разложение** (ваш единогласный снос):
  CAGR выручки / прибыли / EPS, вклад изменения числа акций, тренд маржи;
  при расхождении компонент — метка LOW_CONFIDENCE и исключение
  из сравнимого рейтинга.
* **Сторожа ложной дешевизны** (каждый ваш пример станет пином): пик цикла
  (Micron-2018), смена режима вниз (Zoom/PYPL-2022, Intel-2021), перегиб
  вверх (NVDA-2023), выкупный EPS-рост (O'Reilly) с флагом выкупа в долг.
* **Терминальная доходность**: отрицательный/нулевой капитал — отказ
  NOT_APPLICABLE (не потолок); потолок 40% только для валидных ROE; курс
  на ROIIC — отдельным решением после пилота.
* **Ставка**: 12% едина; в каждый прогон встроена сетка 10–14% с ранговой
  корреляцией; ρ < 0.98 переоткрывает вопрос (арбитраж ChatGPT: измерить,
  не предполагать; бета как вход отклонена как ценовая и нестабильная).
* **Пиры** — только флаги/процентили, никогда входы (закрыто обоими,
  апелляция снята).
* **Внеиндексные имена оператора** (19 шт.) — физически отдельный файл:
  факты SEC да, модельные числа и качественные суррогаты вердиктов — нет.
* **Метрики**: Spearman Rank IC (12 мес., первичный), верхний−нижний
  квинтиль, бенчмарк — равновзвешенный универсум (QQQ вторичный); первый
  живой год — только стабильность рангов.
* **Заморозки**: полный протокол проверки №2 фиксируется до просмотра
  результатов проверки №1; список параметров, разрешённых к изменению между
  проверками, объявляется заранее. **Модель маржи — до проверки №2**
  (ваше единогласное требование; порядок работ перестроен по 13-шаговой
  схеме ChatGPT). Календарные сроки заменены воротами приёмки.
* Поправка в нашу пользу: численный решатель обратного расчёта уже написан
  и работает (итеративный, в коде с v4.2.68) — «писать с нуля 4–6
  чейнджсетов» не требуется; остаются угловые случаи (отрицательный EPS
  и т.п.).

# ЧАСТЬ 2. НАХОДКИ НА GITHUB — prior art

Мы провели поиск; ниже находки и наша оценка. **Просьба №1: проведите свой
поиск** — включая не-GitHub (готовые сервисы, академические реализации) —
и дополните тем, что мы пропустили.

## 2.1. `Keenan-ux/implied-expectations` — главная находка

Python-библиотека (MIT, PyPI, v0.1.0, июль 2026; один автор; 0 звёзд —
проект свежий и непроверенный сообществом). Обратный расчёт ожиданий
по Раппапорту-Мобуссену поверх SEC EDGAR companyfacts. Сверка с нашей
конструкцией, выработанной за два раунда:

| Наше решение | У них |
|---|---|
| обратный расчёт: рост/срок/маржа, зашитые в цену | ядро: три режима решения (growth / years / margin) |
| отказ вместо правдоподобного числа | дословно: «solver never fabricates a number»; убыточные — отказ; банки/страховые — отказ с объяснением причины |
| сетка чувствительности по ставке | встроена: рост × ставки 7.5–11.5% × горизонты 5/10/15 лет |
| реинвестирование как цена роста | формула reinvestment = g/ROIC — ровно то, что вы рекомендовали нам вместо ROE |
| каждое допущение с источником | таблица всех допущений с XBRL-тегами происхождения; «nothing is a black box» |
| пины, посчитанные вручную; независимые перекрёстные проверки | тесты: «ожидаемые числа выведены на бумаге, не кодом под тестом»; round-trip к 1e-8; независимая перекрёстная реализация; golden-тесты на замороженных филингах |
| терминальная стоимость без второй истории роста | терминальный ROIC = ставке ⇒ терминальный рост value-neutral, заявлено осознанным решением |

Их честно названные ограничения (совпадают с нашими нерешёнными пунктами):
маржа плоская, без затухания и режимов; данные только trailing; ставка
плоская; убыточные не считаются; только США.

**Чего у них нет и что остаётся нашим:** историческая реконструкция
«на дату» (as-of), пре-регистрированная валидация, дисциплина
сплитов/дивидендного дрейфа на живых данных, рейтинг универсума, сторожа
режимов.

## 2.2. boothcheck.com (упомянут в их README)

Сервис того же класса, тяжелее: ставка на компанию, сегментный разбор,
**mid-cycle нормализация для циклических** — это значительная часть нашей
«модели маржи» и сторожа пика цикла в готовом виде; предрасчёт для ~1950
акций США; бесплатный публичный MCP-endpoint. Нами глубоко не проверен.

## 2.3. `dgunning/edgartools` (~2.6 тыс. звёзд, зрелая, активная)

Библиотека чтения EDGAR/XBRL: 10-K/10-Q, финансовые стейтменты, типизация.
Наш `edgar_facts.py` переизобретает её часть — но наша версия несёт
выстраданное на инцидентах: as_of-фильтр, подтверждение сплитов повторными
подачами, различение «нет данных»/«ноль», обнаружение конфликта тегов,
происхождение каждого числа.

## 2.4. `virattt/ai-hedge-fund` (~63 тыс. звёзд)

Мультиагентный «фонд» с агентами-персонами (Buffett, Munger и т.д.). Это
архитектура, которой Консилиум был в первой версии — и которую ваш же аудит
демонтировал (арбитраж агентов: 63% стоимости при невлиянии на вердикт).
Полезен как зеркало: самый популярный проект жанра — ровно то, от чего
мы ушли по вашим доводам.

## 2.5. Прочее

`halessi/DCF` (~500 звёзд, прямой DCF на данных FinancialModelingPrep);
`sughanthAM/reverse-dcf-model` (NSE, Streamlit, свежий);
`rollingSirius/equity-research-skill` (~240 звёзд, скриптованный DCF/EPV
как AI-skill, китайский рынок).
