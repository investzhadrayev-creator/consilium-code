# РЕШЕНИЯ ПО ИТОГАМ РАУНДА 5 + ЭКСПЕРИМЕНТ

Оба рецензента дали вердикт **(б)**: массовый радар на ~100 имён не строится;
система перепрофилируется. Оператор решения принял. Ниже — зафиксированный
итог арбитража и новый затвор.

---

# 1. АРХИТЕКТУРА (принято единогласно по раунду 5)

Три компонента вместо одной машины:

**Этаж 1 — discovery (еженедельно, дёшево).** Карточка по watchlist
(~34 имени) из двух половин:
- фактовая половина — генерируется автоматически ИЗ СОБСТВЕННОЙ базы
  проекта (SEC EDGAR в PostgreSQL + цены Tiingo): рост выручки 3/5 лет
  и ускорение, маржа против медианы, траектория EPS рядом с NI/FCF,
  денежная конверсия, изменение числа акций, чистый долг, относительная
  сила против VOO/QQQ. Плюс три дешёвых сторожа-флага: пик цикла,
  расхождение EPS↔FCF, вклад выкупов в рост EPS;
- ожиданиевая половина — консенсус, пересмотры, сюрпризы, реакция цены
  на отчёт — смотрится ГЛАЗАМИ на бесплатных страницах (Zacks detailed
  estimates и аналоги) только по 3–5 именам, отобранным фактовой половиной.
  Платные подписки/API на старте НЕ покупаются; вопрос автоматизации
  этого слоя откладывается до измеренной потребности.

**Этаж 2 — Consilium как рентген перед покупкой (по запросу, дорого).**
Досье одного имени ≤2 часов: as-of факты с provenance, разложение
«что просело и почему», сторожа (включая новый сторож долга-под-выкупы —
минус 5 от AI Studio), сценарная поверхность вместо одного числа
(маржа × множитель × требуемый рост — конструкция ChatGPT), консенсус
рядом с требованием (missing → CONSENSUS_UNAVAILABLE, GAAP/non-GAAP
basis check обязателен).

**Этаж 3 — журнал решений (предложение ChatGPT, принято).** Неизменяемая
запись каждого решения ДО исхода: дата, цена, тезис, что должно быть
правдой, что опровергло бы, решение оператора и почему.

## Принятые арбитражи спорных пунктов

| Спор | Решение |
|---|---|
| EPS Surprise в карточке | остаётся, ВМЕСТЕ с полем «реакция цены на отчёт» (снимает возражение AI Studio про low-balling) |
| MELI 1.09x | косметический пол 10x НЕ вводится; формула обязана отказывать при нестабильной терминальной экономике (доменный сторож снизу) |
| GOOG / мультикласс | в универсуме; отказы — дефект стенда, чинится |
| Иностранные филеры (20-F/40-F) | отдельный ярус с меткой UNSUPPORTED_FILING_REGIME, не «экономическая неприменимость» |
| Данные | edgartools как parser substrate + собственный семантический слой (as-of, basis, provenance, refusal остаются нашими); META и GOOG — обязательные regression-goldens адаптера |
| Балласт | из активного пути выводятся: BUY/NO-BUY, порог 12%, скалярный ранг required−historical, массовый исторический прогон как продукт, PIT-инфраструктура универсума как ежедневное требование. Код остаётся в репозитории как regression-корпус (append-only) |

# 2. ПРАВИЛО КОНФЛИКТА ЭТАЖЕЙ (решение 2 оператора — принято)

Записывается заранее, действует механически:

- Этаж 1 негативен → имя не номинируется; этаж 2 не запускается.
- Этаж 1 позитивен → имя допускается на этаж 2. Это НЕ сигнал покупки.
- Этаж 2 показывает: требования вне зарегистрированного диапазона /
  режимный риск / неразрешённый конфликт данных → новая позиция
  НЕ открывается, какими бы сильными ни были пересмотры.
- Оба этажа согласны → ELIGIBLE_FOR_OPERATOR_DECISION. Решение — человек.
- «Дёшево по этажу 2, но пересмотры падают» → WATCH, не покупка
  (не ловить ножи). Отступление возможно только как задокументированный
  override в журнале решений, не как правка правила.

# 3. НОВЫЙ ЗАТВОР ВМЕСТО ПИЛОТА NFLX (решение 1 оператора — принято)

## 3.1. Формулировка

STOP BUILD от 2026-08-09 не отменяется молча — его затвор ЗАМЕНЯЕТСЯ.
Разрешён ТОЛЬКО следующий ограниченный эксперимент; всё вне списка
остаётся под запретом:

1) скрипт фактовой карточки этажа 1 поверх собственной базы по watchlist;
2) адаптер edgartools + шаблон досье этажа 2; goldens: MU, INTC, META, GOOG;
3) экзамен NFLX-FY2019 (см. 3.2) как первое досье;
4) ещё 2–3 живых досье по именам, номинированным этажом 1;
5) журнал решений;
6) бэктест панели режима рынка на публичной истории (по итогам раунда 6).

Обязательные траты: нет. Ожидания рынка — глазами на бесплатных страницах.

## 3.2. Судьба пилота NFLX-FY2019

Пилот НЕ отменён. Он включён в эксперимент как досье №1 и сохраняет
смысл экзамена: NFLX FY2019 — эталонный случай «бумажная прибыль
положительна, денежный поток глубоко отрицателен». Перекалиброванный
сторож денежного распада ОБЯЗАН дать RED. Молчание сторожа на этом
кейсе = провал экзамена = сторож не считается починенным.

## 3.3. Критерии остановки (записаны ДО старта; провал любого —
автоматизация останавливается, остаются готовые инструменты + чек-лист)

- покрытие обязательных полей фактовой карточки ≥95% по watchlist,
  либо named limitation источника;
- еженедельное обновление карточки ≤30 минут времени оператора
  после настройки;
- 0 выдуманных/подставленных значений; missing остаётся missing;
- минимум 3 полных досье этажа 2; медианное время ≤2 часов;
- NFLX-экзамен: сторож даёт RED;
- META и GOOG читаются адаптером без ручной починки парсера
  внутри аналитической сессии;
- каждое досье завершается блоком «что должно быть правдой /
  что опровергнет тезис»;
- ни одной правки правил задним числом внутри периода.

Горизонт эксперимента: 4 недельных цикла выходных (календарно — по факту
занятости оператора; дедлайна нет, спешка запрещена). По завершении —
отчёт по критериям и решение оператора о следующем шаге.
