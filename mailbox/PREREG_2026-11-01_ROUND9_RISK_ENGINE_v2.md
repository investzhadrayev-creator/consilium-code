## 3. Определения метрик
- Выручка: цепочка тегов выручки адаптера К2 (та же, что в карточке этажа 1).
- Рост г/г (TTM) = TTM / TTM четырьмя кварталами раньше − 1.
- Рост квартала г/г = квартал / тот же квартал год назад − 1. Рост кв/кв = квартал / предыдущий квартал − 1.
- Ускорение = рост квартала г/г минус рост предыдущего квартала г/г. Замедление два квартала подряд = ускорение < 0 в двух последних кварталах.
- Валовая маржа (квартал и TTM) = (выручка − себестоимость) / выручка; при наличии тега GrossProfit — он, иначе производная из одной подачи (derived=true).
- FCF = операционный денежный поток − capex (PaymentsToAcquirePropertyPlantAndEquipment; запасной тег — по цепочке карточки). FCF после SBC = FCF − ShareBasedCompensation.
- SBC в % выручки = SBC за TTM / выручка за TTM.
- Две метрики числа акций (обе всегда показываются рядом):
 - ОСНОВНАЯ — среднее число акций за квартал (A_avg): us-gaap:WeightedAverageNumberOfDilutedSharesOutstanding за дискретный квартал из 10-Q. Почему основная: (1) это поток за тот же период, что и выручка, — честная пара для «выручки на акцию»; (2) одно число в каждом 10-Q, без проблем классов и без сдвига даты обложки; (3) воспроизводимо. У убыточных компаний разводнённое = базовое (опционы не учитываются), это нормально. Q4 = 4 × среднее за ФГ − (Q1 + Q2 + Q3), пометка derived=approx; если результат вне [0,9 × Q3; 1,5 × Q3] — отказ Q4_UNDERIVABLE. Недостаток: среднее запаздывает — выпуск в конце квартала виден полностью только в следующем.
 - ВСПОМОГАТЕЛЬНАЯ — на конец периода (A_end): dei:EntityCommonStockSharesOutstanding с обложки; запасной вариант — us-gaap:CommonStockSharesOutstanding на дату баланса. Несколько классов — сумма только если раскрыты все классы, иначе отказ MULTI_CLASS_NOT_SUMMED. Назначение — раннее предупреждение: выпуск через ATM виден сразу. В сигнал размытия НЕ входит; если по A_end условие сигнала выполнено, а по A_avg нет — флаг «раннее предупреждение (на конец периода)», без уровня.
 - Полностью разводнённое количество (опционы, варранты, конвертируемые) показывается отдельно, если размечено; в сигнал не входит.
 - Структура Up-C (классы B/C — паи операционной компании, обмениваемые на класс A; признак — доля неконтролирующих владельцев или паи в XBRL): средние класса A не отражают экономическое число акций, обмен паёв выглядит как размытие. Для таких эмитентов сигнал размытия — НЕ ОПРЕДЕЛЁН (UP_C_ECONOMIC_COUNT_UNTAGGED), если экономическое число (A + паи) не размечено.
- Рост числа акций квартала S_g(q) = A_avg(q) / A_avg(q − 4) − 1 (тот же квартал год назад — без сезонности).
- Рост выручки квартала R_g(q) = выручка(q) / выручка(q − 4) − 1.
- Выручка на акцию RPS(q) = выручка(q) / A_avg(q); рост RPS_g(q) = (1 + R_g(q)) / (1 + S_g(q)) − 1. «Акции растут быстрее выручки» в квартале q ⇔ S_g(q) > R_g(q) ⇔ RPS_g(q) < 0.
- Разрыв размытия G(q) = S_g(q) − R_g(q) (в процентных пунктах).
- Для справки показываются и годовые S_g по A_end (обложки с разницей 4 квартала).
- Runway в кварталах = (деньги и эквиваленты + краткосрочные вложения, без ограниченных денег) / среднее квартальное сжигание за 2 последних квартала, где сжигание = −FCF квартала. Если FCF ≥ 0 в обоих кварталах — «не сжигает» (числа нет, сторож не применим).
- Финансирование за 90 дней = в индексе подач есть 424B5/424B3 (размещение), 8-K с пунктом 1.01 / 2.03 / 3.02 или закрытие конвертируемого долга. Показывается ссылкой; объём — только если размечен в XBRL, иначе «объём не извлечён».
- Активные shelf/ATM = S-3 / S-3ASR / 424B5 за 36 месяцев. Факт подачи и ссылка, без извлечения объёма из текста.
- Инсайдеры (Form 4) за 3 и 12 мес.: учитываются только рыночные сделки — код P (покупка) и код S (продажа). Коды A, M, F, G, C и прочие не считаются покупками и продажами. Продажа по плану 10b5-1 (флаг формы) показывается отдельно. Суммы в $ — из полей формы.
- AI-инфраструктура: capex/выручка за TTM; совокупный долг (цепочка тегов долга карточки), его изменение за 4 кв.; доля крупнейшего клиента — только если размечена в XBRL без размерностей, иначе отказ NOT_TAGGED.
- IPO: дата листинга = дата первой котировки Tiingo, сверяется с датой 424B4/S-1. Lock-up — только из файла вех (вносит человек), машина следит за датой.

## 7. Оценка (рисковая часть, порог 20% годовых на 5 лет)
- Цена P, акции N на конец периода, чистый долг D (для «AI-инфраструктуры» — по EV; для остальных D = 0, если чистый долг отрицательный, денежный избыток не добавляется).
- Акции через 5 лет: N5 = N × (1 + max(S_g, 0))^5, где N = A_end на последнюю дату (стоимость делится на акции, существующие сейчас), S_g — рост A_avg за последние 4 кв. (размытие продолжается текущим темпом; консервативно). Если A_end не определено — N = A_avg последнего квартала с пометкой.
- Необходимая выручка через 5 лет: R_need = (P × 1,20^5 × N5 + D) / M, где M — зрелый мультипликатор (EV/выручка) типа.
- M по отраслям (предложение архитектора; утверждается одобрением этого файла; в карточке всегда чувствительность при 0,5×M и 1,5×M): космос и спутниковая связь — 5; квантовые вычисления — 8; ядерная энергетика — 4; AI-инфраструктура (дата-центры, облако GPU) — 6; голосовой/прикладной AI-софт — 8. Отрасль имени записывается в config/risk_sectors.csv до первого прогона.
- Сравнение: R_need против гайденса и консенсуса. Гайденс — ручная запись с датой и источником; консенсус в бесплатных источниках недоступен → «НЕДОСТУПНО», если не внесён вручную с датой и источником.
- Сценарии bear/base/bull: выручка через 5 лет и вероятности (сумма = 1) вносит аналитик в файл с автором и датой ДО расчёта; помечаются «вход аналитика, не факт». Машина считает доходность сценария r_s = ((R5_s × M − D) / N5 / P)^(1/5) − 1, ожидаемую доходность (взвешенно), отношение «потенциал / потеря» = Σ p_s × max(V_s − P, 0) / Σ p_s × max(P − V_s, 0), где V_s = (R5_s × M − D) / N5, и чувствительность к вероятностям (±10 п.п. на bull ↔ bear).
