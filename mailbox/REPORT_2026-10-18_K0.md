## Не закрыто / наблюдения

1. Класс дефекта шире двух файлов: любой тест, читающий часы, снова состарится. Полный аудит других тестов на зависимость от даты не делался; в этой задаче лечились только падавшие.
2. `tests/test_e2e_result_vs_tables.js` кэширует фикстуру в `/tmp/ma_result.json` и проверяет только `existsSync`. Если генерация провалилась (у меня — из-за отсутствия flask), остаётся 0-байтовый файл, и следующие прогоны падают с `Unexpected end of JSON input` без связи с причиной. Это не вызвало красного базового прогона (там фикстуры не было), но хрупко; код не менял, по запросу — отдельной задачей.
3. Контракт окна: «Latest reported quarter» помечается началом квартала, поэтому свежеотчитанный квартал выпадает из «катализаторов» через ~190 дней после его начала (≈3 мес. после отчёта). Это решение дизайна, а не ошибка; продуктовое ли оно — вопрос архитектору.
4. Контроль мутационного каталога не расширялся (остаётся 149), чтобы не менять DoD; новые пины проверены ручными мутациями выше, не каталогом.
