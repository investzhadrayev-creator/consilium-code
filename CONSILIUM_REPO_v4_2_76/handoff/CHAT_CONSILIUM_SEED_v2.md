## 2. РЕЕСТР ДЕЙСТВУЮЩИХ ПРАВИЛ ПРОТОКОЛА

1. **ALL GREEN** = exit-код `run_tests.py` равен 0 и назван явно; иначе пакет не принят.
2. **Непрочитанная проверка не пройдена** — после каждой правки любого артефакта грепать файл.
3. **Диагноз дефекта — по сырому логу источника**, не по симптому и не по докладу.
4. **Меняешь топологию → бампаешь meter map** (на ней держится весь учёт денег).
5. **Один чейнджсет — одна цель**; исключение только санкцией архитектора.
6. **Determinism scorecard — обязательная секция каждого пакета** по паре.
7. **Claude — гейткипер, не подгонятель:** при регрессии эскалирует, не переписывает тесты молча.
8. **Утверждение об отсутствии требует доказательства применимости** — `assert X == []` без
   доказательства, что механизм МОГ найти X, есть пустое место.
9. **Величина никогда не признак дефекта; признак — ПРИЧИНА.**
10. **Живая проверка сильнее двух пар глаз** — гипотезы задаёт рассуждение, проверку делают числа.
11. **Структурная защита выше обнаружения:** нарушение должно стать недостижимым, а не
    обнаруживаемым (образцы: `shares_used`, `_pub` + grep-пин `# LEG-OK`).
12. **Структурная защита обязана покрывать ВСЕ поверхности публикации** — их семь, перечень в
    HANDOFF секция OO; закрытие одной оставляет класс живым в другой.
13. **Всякое публикуемое число следует вердикт-ноге;** где обе информативны — `_by_leg` с
    вердиктной как основной.
14. **`A || B` с дефектным A эквивалентен дефекту** — аудит проверяет ПОРЯДОК источников, а не
    факт чтения RESULT.
15. **Ноль не есть неизвестно; отсутствие данных не есть чистота** — нужна третья категория
    («не знаю»), а не молчание.
16. **Любое новое поле качества определяет поведение для доисторических данных ПРИ
    ПРОЕКТИРОВАНИИ**; «отсутствует» значит другой декодер, а не `false`.
17. **Расширение контракта модель↔парсер создаёт формы нарушения, не покрытые существующими
    защитами по определению** — санация и негативный контроль в ТОМ ЖЕ чейнджсете.
18. **Стейл-словарь в промпте — исполняемая спецификация, а не документация.**
19. **Пустоты прячутся под самыми важными инвариантами** — главные правила старше всех, сьют вырос
    вокруг них и создал иллюзию покрытия косвенностью. Проверку начинать с «очевидно покрытых».
20. **Инструмент, мутирующий код, обязан убирать всё производное** — грязь переживает
    восстановление (`__pycache__`) и отравляет последующие наблюдения.
21. **`min()` по окнам — усилитель дефектов одного знака:** гарантированно выбирает окно,
    загрязнённое в сторону занижения.
22. **Предсказание до измерения — обязательная часть каждого пакета.** Пре-регистрированное
    ожидание ловит отказ там, где зелёный отчёт выглядит нормальным (окупилось с первого
    применения: расхождение с предсказанием вскрыло неработающий фикс выручки).
23. **Годность данных судится по ОКНУ ИСПОЛЬЗОВАНИЯ, а не по целому ряду.** Дыра вне всех окон не
    может испортить якорь, вычисленный внутри них; абсолютное условие вместо относительного
    молчало целый оплаченный прогон.
24. **Качество выше сроков. Дедлайна запуска нет.** Источник: решение ОПЕРАТОРА от 21.07
    (работа в ритме выходных и вечеров; внешние даты — факты, а не дедлайны). Это не аксиома
    проекта, а его решение — меняется им же.

## 3. ОТКРЫТЫЕ ОЧЕРЕДИ

**У каждой задачи указан ИСПОЛНИТЕЛЬ и требуемая способность.** Claude работает в контейнере без

Всё на кэше, стоимость ноль. **Решение о снятии слоёв — оператора, на цифрах, а не на доводах.**
