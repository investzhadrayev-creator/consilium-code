# Consilium — правила для автоматического исполнителя (claude[bot])

Проект: auditable-инструмент анализа акций. Оператор — частный инвестор;
архитектор ставит задачи через Issues (почтовый мост); ты исполняешь.

## Железные правила
1. Результат — ТОЛЬКО через PR. Прямые коммиты в main запрещены.
2. Append-only: существующие файлы mailbox/, journal/ не редактируются
   и не удаляются; исправление — новым файлом с supersedes в шапке.
3. Missing ≠ zero ≠ default. Неизвестное — именованный отказ с причиной,
   никогда правдоподобная подстановка. Это главный инвариант проекта.
4. Каждое число тащит provenance (accession SEC / источник / дата).
5. Числа в отчётах — только с выхода инструментов, не из памяти.
6. Не трогай каталоги CONSILIUM_REPO_v4_2_* кроме новейшего
   (CONSILIUM_REPO_v4_2_83 — рабочее дерево кода), docs/HANDOFF*, Reports/
   прошлых прогонов.
7. Тесты: python3 run_tests.py в CONSILIUM_REPO_v4_2_83 (602+) и
   tools/mutation_probe.py (149 RED) должны оставаться зелёными; к новому
   коду — consumer-tests.
8. Контекст решений: mailbox/DECISION_2026-10-11_ROUND7_REBOOT.md,
   mailbox/PREREG_2026-10-11_EXPERIMENT_v2.md. Протоколы заморожены.
