# CHANGELOG — история версий Consilium Spine

Один дом для чисел о собственной работе. Заведён 6 августа 2026 после того, как
аудиторский пакет ушёл к внешним рецензентам с цифрами «477 тестов и 108 мутаций»,
которых ни в одной версии не существовало.

---

## Правила ведения — обязательны

1. **Строка добавляется в тот же чейнджсет, что и версия.** Не после, не пачкой.
2. **Числа берутся с выхода команд, не из памяти и не из другого документа.**
   Источник — ровно эти три:
   ```
   npm install
   python3 run_tests.py            → строка "Ran N tests" + "ALL GREEN" + exit-код
   python3 tools/mutation_probe.py → строка "catalogue: N cases, N RED, N SKIP, N GREEN"
   ```
3. **Базис едет с числом.** Измеренное на прогоне и посчитанное статически по файлам —
   разные величины и помечаются по-разному. Сравнивать их между собой нельзя.
4. **Неизвестное называется неизвестным.** Пустая клетка запрещена; пишется
   `НЕ ВОССТАНОВЛЕНО` с причиной.
5. **Строки не переписываются.** Ошибку в прошлой строке исправляет новая строка
   с пометкой, а не правка старой.

## Известное ограничение этого файла

Пока строки заполняет человек или чат, файл остаётся прозой о числах и способен
разойтись с кодом — тем же способом, каким разошёлся аудиторский пакет.
Предупреждение в тексте ограничителем не является. Планируется структурная проверка,
которая краснеет при расхождении числа в документе с выходом инструмента, вместе
с негативным контролем, доказывающим, что она способна покраснеть. До тех пор
единственная защита здесь — дисциплина, и это записано как слабое место, а не как решение.
