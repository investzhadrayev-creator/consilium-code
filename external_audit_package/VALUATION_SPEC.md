## 1. Что вычисляет модель

Модель отвечает на один вопрос: **какую цену можно заплатить сегодня, чтобы владение
акцией принесло требуемую доходность за десять лет.**

Она НЕ прогнозирует цену акции, НЕ выставляет целевых цен на 12–18 месяцев и НЕ
рекомендует сделок. Это ограничение зафиксировано как конституционное.

## 2. Формулы

### 2.1. Траектория прибыли

```
e(0) = base                       базовая величина на акцию
для y = 1..Y:
    g(y) = g                             если fade = false, либо y ≤ 5
           g + (tg − g)·(y − 5)/(Y − 5)   если fade = true и y > 5
    e(y) = e(y−1) · (1 + g(y))
```

`ivc_lib.py:41-44`.

| Переменная | Смысл | Единица | Источник |
|---|---|---|---|
| `base` | прибыль или FCF на акцию за последний отчётный год | валюта/акция | EDGAR, выбор см. §2.2 |
| `g` | базовый темп роста | доля/год | якорь роста, см. §5 |
| `tg` | терминальный темп | доля/год | константа 0.04, см. §7 |
| `Y` | горизонт | лет | 10 (`years`, по умолчанию 10) |
| `fade` | включено ли затухание | булево | по умолчанию true |

Затухание **линейное по годам 6…Y**, полный темп держится первые пять лет.

### 2.2. Выбор базы (двигатель расчёта)

```
если eps_normalized > 0        → engine = "eps",           base = eps_normalized
иначе если fcf_per_share > 0   → engine = "levered_fcf_ps", base = fcf_per_share
иначе                          → ошибка "Category-F, IVC N/A"
```

`ivc_lib.py:30-33`. Отрицательная или нулевая база на обеих ветках означает, что модель
неприменима (см. §20).

Важно: **это выбор внутри одного вызова.** Двойная оценка (по прибыли и по денежному
потоку) реализована выше, в `app.py`, двумя независимыми вызовами `ivc()` с разными
входами; вердикт берётся по худшему из двух результатов (см. §19).

### 2.3. Разводнение

```
epsT_adj = e(Y) / (1 + dil)^Y
```

`ivc_lib.py:45`. `dil` — среднегодовой темп изменения числа акций (`share_dilution_cagr`).
Положительный — выпуск, отрицательный — выкуп.

**Защита:** при `|dil| > 0.20` значение обнуляется и поднимается флаг
`dilution_cagr_..._REJECTED_likely_split_artifact` (`ivc_lib.py:26-29`). Причина —
исторический случай: сплит 10:1 у NVDA дал бы деление терминальной прибыли на 95.

### 2.4. Стоимость через Y лет и приведение

```
FV(Y) = epsT_adj · pef
IV    = FV(Y) / (1 + disc)^Y + PV(дивиденды)
```

`ivc_lib.py:55-59`.

| Переменная | Смысл | Значение |
|---|---|---|
| `pef` | выходной множитель к прибыли | см. §6 |
| `disc` | ставка дисконтирования | равна `hurdle`, по умолчанию 0.12 |
| `hurdle` | требуемая доходность | 0.12 |

Ставка дисконтирования **детерминирована и не берётся у модели**: в `app.py`
`"discount_rate": _hurdle` с комментарием «= hurdle (mandate A); llm_disc записывается,
но не рулит». Значение, предложенное LLM, сохраняется отдельно и служит канарейкой.

### 2.5. Подразумеваемая доходность

```
implied_CAGR = ((FV(Y) + FV_дивидендов) / price)^(1/Y) − 1
```

`ivc_lib.py:60`. Это ответ на вопрос «какую доходность даёт покупка по текущей цене».

### 2.6. Запас прочности и лестница входа

```
MoS% = (IV − price) / price · 100

для каждой ступени t ∈ {0.10, 0.20, 0.30}:
    порог_покупки = IV / (1 + t)
    доходность_на_пороге = ((FV(Y) + FV_див) / порог)^(1/Y) − 1
```

`ivc_lib.py:63-71`. Обратите внимание: порог считается **делением** `IV/(1+t)`, а не
умножением `IV·(1−t)`. Это принципиально: при t = 0.30 деление даёт скидку 23.1% от IV,
а не 30%; зато выполняется тождество «от порога до IV ровно t процентов роста».
Тождество проверяется в самом расчёте (`selftest_mos_at_threshold_ok`).

Действующая ступень — базовая 20%, повышается только направленными сигналами
(переворот вердикта, устойчивые блокирующие замечания, расхождение знака доходности).

### 2.7. Дивиденды

```
d0    = price · dividend_yield
PV_д  = Σ(y=1..Y) d0·(1+dg)^(y−1) / (1+disc)^y
FV_д  = Σ(y=1..Y) d0·(1+dg)^(y−1) · (1+disc)^(Y−y)
```

`ivc_lib.py:56-58`. Дивиденды входят и в приведённую стоимость, и в подразумеваемую
доходность (реинвестированными по ставке дисконтирования).

`dividend_growth` берётся из ряда `CommonStockDividendsPerShareDeclared` EDGAR; при
подтверждённом сплите внутри окна ряд отвергается с флагом (`dps_series_refused_split_in_window`),
отсутствие ряда — отдельный флаг `dps_series_absent`. «Отказано как недостоверному»
и «эмитент не платит» не делят одно сообщение.

### 2.8. Справочная точка пятого года

```
year5_reference = (e(5)/(1+dil)^5) · pef / (1+disc)^5
```

`ivc_lib.py:52-54`. Публикуется **только со сноской**: срез на пятом году обрывает
траекторию до конца затухания и потому систематически оптимистичен. Вердикт по нему
не выносится.

`ivc_lib.py:72-85`:

## 4. Ответы на вопросы аудитора

**1. Учитываются ли денежные потоки за годы 1–10 или только терминальная стоимость?**
Только терминальная — плюс дивиденды, если они есть (§2.7). Промежуточная нераспределённая
прибыль не дисконтируется отдельно: предполагается, что она отражена в терминальной
прибыли через рост. Это **сознательное упрощение** классической модели «прибыль ×
множитель», а не DCF. Уязвимость: компания, распределяющая почти всю прибыль, и компания,
реинвестирующая её полностью, при равном росте получают одинаковую оценку.

**2. Дивиденды** — §2.7, входят в IV и в доходность.

**3. Выкупы акций** — только через `share_dilution_cagr` (отрицательное значение).
Отдельного учёта суммы выкупа нет.

**4. Выпуск акций и SBC.** Выпуск — тот же `dilution_cagr`. SBC участвует **в скоринге
качества** (отношение SBC к выручке) и в различении «gross до выкупов / net после
выкупов» на FCF-ноге. Прямого вычитания SBC из прибыли **НЕ РЕАЛИЗОВАНО**.

**5. FCFF или FCFE?** Используется **levered FCF на акцию**, то есть ближе к FCFE.
Формального определения в терминах FCFF/FCFE в коде нет — **НЕ ОПРЕДЕЛЕНО** явно, что
является дефектом документации.

**6. Equity multiple или EV multiple?** Только **equity** (множитель к прибыли на акцию).
EV-подход **НЕ РЕАЛИЗОВАН**.

**7. Cash, debt, аренда, доли меньшинства, инвестиции.**
В формулу оценки **не входят вообще**. Долг влияет только на балл качества бизнеса
(отношение долга к капиталу). Аренда, доли меньшинства, инвестиции в ассоциированные
компании — **НЕ РЕАЛИЗОВАНЫ, не упоминаются в коде.** Это принципиальный пробел:
компания с чистой денежной позицией и компания с высоким долгом при равной прибыли
получают одинаковую оценку.

**8. Diluted shares.** Один знаменатель на обе ноги (`shares_used`), тег DEI исключён.
Инвариант защищён пином и мутацией.

**9. Отрицательные EPS и FCF.** Отрицательная база на обеих ветках → отказ расчёта
(`Category-F`), см. §20.

**10. Финансовые компании, REIT, сырьевые, компании без стабильной прибыли.**
**НЕ РЕАЛИЗОВАНО.** Никакой отраслевой развилки в коде нет. Для банков не заведено
понятие выручки; для REIT нет FFO; для циклических компаний нет нормализации по циклу.
Ожидаемое поведение — деградация качества данных и флаги, но это **гипотеза, не
проверенная измерением**: SOFI и NVO стоят в очереди валидации и ещё не прогонялись.

**11. Исторический темп роста.** Якорь = **минимум** из темпов за 3 и 5 лет,
вычисленных как CAGR по конечным точкам, из рядов EDGAR. Отдельно считается медиана
годовых приростов — она используется во второй, справочной оценке (§18).

**12. Эффект низкой базы, поглощения, циклический пик.**
**НЕ РЕАЛИЗОВАНО.** Ни выявления поглощений, ни нормализации по циклу, ни защиты от
низкой базы в коде нет. Частичная косвенная защита — минимум из двух окон (§11) и
затухание, но это не решение задачи.

**13. Затухание** — §2.1, линейное на годах 6…10.

**14. Выбор терминального множителя** — §6.

**15. Совместимость множителя, терминального роста и реинвестирования.**
Формально **не обеспечивается**. Множитель берётся из истории, терминальный рост —
константа 4%, реинвестирование не моделируется. Согласованность (например, по формуле
Гордона) не проверяется. Это известный методологический пробел.

**16. Запас прочности** — §2.6.

**17. Как меняется доходность после применения запаса?**
Считается явно для каждой ступени (`implied_cagr_at_threshold_pct`). При покупке по
порогу доходность выше требуемой ровно на величину ступени в терминах цены.

**18. «Центральная» и «консервативная» оценки.**
Консервативная (вердиктная): минимум окон роста, множитель с потолком, вердикт по
худшей ноге. Центральная (справочная): медиана годовых приростов, множитель без
абсолютного потолка, те же затухание и ставка. Отличий ровно два, чтобы дельта
изолировала именно эти решения. Центральная **не влияет** ни на вердикт, ни на
лестницу, ни на алерты — защищено структурно и пином.

**19. Почему вердикт по минимуму из прибыли и FCF?**
Асимметрия цены ошибки: переплата стоит капитала, пропущенная идея — доходности.
Известное следствие, признанное дефектом: у компаний с большими инвестициями в рост
FCF занижен структурно (META: база FCF 17.91 против GAAP 23.49, разрыв −34%), и они
систематически получают более строгий вердикт. Вопрос «различает ли FCF-нога капзатраты
роста и поддержания» открыт.

**20. Условия MODEL_NOT_APPLICABLE.**
- нет цены или цена ≤ 0 → `RUNNER_ERROR: price missing`;
- нет темпа роста или множителя → `RUNNER_ERROR`;
- нет положительной базы ни по EPS, ни по FCF → `Category-F, IVC N/A`;
- рост > 40% → флаг `BLOCKING`, гейт FAIL;
- рост > 25% без затухания → затухание принудительно включается.

## 5. Якорь роста

`app.py`: `_anchored_g = min(_anchor_candidates)` — минимум по двум окнам (3 и 5 лет).
Правило покрытия: сплошной ряд требуется **для окон, входящих в якорь**, а не для всего
ряда. Один тег на весь ряд; смена тега/единицы/формы — дефект провенанса.

Мутация `anchor-01` (min → max) обязана краснить пин.

## 6. Выходной множитель

```
pef = min(медиана P/E за 5 лет, медиана P/E за 10 лет, PE_ABS_CAP)
PE_ABS_CAP = 30
```

Внутри `ivc()` дополнительно проверяется вторичный потолок
`min(pe_hist_median, 1.5·pe_sector_median)` — при превышении поднимается флаг MAJOR
(`ivc_lib.py:38-40`). Поле `pe_sector_median` в текущем пайплайне **не производится**,
поэтому вторичный потолок фактически опирается только на историческую медиану.

История решения: предел был 25, поднят до 30 с одновременной персонализацией
(собственная медиана компании) 03.08.2026 по решению оператора. Мутация `ceiling-01`
не даёт молча вернуть 25.

Известный спор: на дорогих секторах предел срезает до трети оценки. Вопрос открыт до
завершения валидационной матрицы.

## 7. Терминальный рост

Константа 4%, применяется асимметрично: `_eff_tg = min(0.04, g)`. Компания, растущая
медленнее 4%, **не ускоряется** в хвосте. Мутация `terminal-01` это охраняет.

## 8. Псевдокод полного расчёта

```
ВХОД: price, eps_normalized, fcf_per_share, revenue_series, pe_history,
      shares_series, dividend_series, hurdle=0.12

1. ЯКОРЬ РОСТА
   g_3y = CAGR(revenue, 3)      g_5y = CAGR(revenue, 5)
   проверить сплошность окон; при разрыве — флаг, окно не используется
   g = min(g_3y, g_5y)

2. МНОЖИТЕЛЬ
   pe = min(median(P/E,5y), median(P/E,10y), 30)

3. РАЗВОДНЕНИЕ
   dil = CAGR(diluted_shares)
   если |dil| > 0.20: dil = 0, флаг «вероятно артефакт сплита»

4. ДВЕ НОГИ
   для base ∈ {eps_normalized, fcf_per_share}:
       если base ≤ 0: нога отказана с причиной
       иначе: IV_нога = ivc(base, g, pe, dil, hurdle)

5. ВЕРДИКТНАЯ НОГА = та, у которой implied_CAGR МЕНЬШЕ
   если построилась одна — прогон объявляется одноногим с причиной

6. ЛЕСТНИЦА ВХОДА
   пороги = IV/(1+t) для t ∈ {0.10, 0.20, 0.30}
   действующая ступень = 20% + направленные сигналы (только вверх)

7. ЦЕНТРАЛЬНАЯ ЛИНЗА (справочно)
   g_c  = медиана годовых приростов выручки за 5 лет
   pe_c = min(median 5y, median 10y)   — без абсолютного потолка
   IV_c = ivc(gaap_base, g_c, pe_c, dil, hurdle)

8. ОБРАТНЫЙ РАСЧЁТ
   найти бисекцией g*, при котором IV(g*) = price
   сравнить g* с фактическим ростом ПРИБЫЛИ (не выручки)
   самопроверка: подстановка g* обязана воспроизвести цену

9. ВЕРДИКТ
   implied_CAGR ≥ hurdle и нет BLOCKING → PASS
   иначе AVOID / WATCH по величине разрыва
```

## 9. Округление и порядок операций

Все промежуточные вычисления ведутся в double без округления; округление применяется
**только при публикации** (`round(...)` в возвращаемом словаре). Множитель печатается
одним форматом во всех поверхностях — после дефекта, при котором в записке стояло «28»
рядом с «27.53» и видимая арифметика не сходилась.

## 10. Что аудитору стоит проверить в первую очередь

1. §4.7 — отсутствие долга, аренды и денежной позиции в формуле оценки. Это самое
   крупное методологическое упрощение, и оно не документировалось до этого пакета.
2. §4.1 — модель «прибыль × множитель», выдаваемая за оценку стоимости: игнорирование
   промежуточных потоков и политики распределения.
3. §4.15 — несогласованность множителя, терминального роста и реинвестирования.
4. §4.10 — отсутствие отраслевых развилок при заявленном списке из 34 имён, включающем
   банк и иностранного эмитента.
5. §6 — абсолютный предел множителя как единственная защита от переоценки роста.
