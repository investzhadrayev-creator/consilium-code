# VALIDATION_MATRIX.md — матрица проверки

**Пакет:** external_audit_package · **дата:** 2026-08-05

Матрица проверяет не «правильную ли цену выдаёт система», а **предсказуемо ли она
ведёт себя на разных типах компаний** — включая те, где она обязана честно отказать.

Метод: перед каждым прогоном записывается ожидаемый **класс поведения** и то, что его
опровергнет. После прогона факт сверяется с записью. Правило, добытое опытом:
пре-регистрация предсказывает поведение системы при известном свойстве данных;
предсказание самого свойства — гипотеза о мире, ей место в анализе, а не в приёмке.

---

## 1. Пройденные имена

### MA — Mastercard, эталон

- **Зачем:** зрелая платёжная сеть, чистая отчётность, высокий исторический множитель.
- **Ожидалось:** якорь роста после исправления дефекта данных даст справедливую цену
  около 458 при пределе множителя 25.
- **Факт:** 457.97 — совпадение с пре-регистрацией до второго знака, подтверждено
  трижды на разных прогонах. При поднятии предела до 30 — 549.56, ровно ×1.20.
- **Расхождения:** нет.
- **Статус:** пройдено. Побитовая стабильность расчёта между двумя прогонами одного дня.
- **Ручная сверка исходных фактов SEC:** выполнена частично — при расследовании дефекта
  валовой выручки (2018–2021 использовался неверный тег, темп роста 6.78% вместо 16.47%).
- **Ручная сверка итоговой оценки:** да, независимым пересчётом.

### META — капиталоёмкая компания

- **Зачем:** проверка поведения при крупных инвестициях в рост.
- **Ожидалось:** прибыль занижена разовыми статьями, денежный поток чище.
- **Факт: ОПРОВЕРГНУТО в обратную сторону.** Занижен денежный поток капзатратами:
  база FCF 17.91 против прибыли 23.49, разрыв −34%, вердиктной стала FCF-нога.
- **Значение находки:** вход в открытый вопрос «различает ли FCF-нога капзатраты роста
  и поддержания». Затрагивает META, AMZN, GOOG, ORCL.
- **Статус:** пройдено, находка зафиксирована.

### NFLX — позиция портфеля

- **Зачем:** проверка на имени, которым оператор владеет.
- **Ожидалось:** центральная (справочная) оценка выше консервативной.
- **Факт:** подтверждено. Консервативная 48.90, центральная 93.30, консенсус аналитиков
  94.33 — **расхождение центральной оценки с консенсусом менее 1%**.
- **Значение:** независимая валидация справочной линзы внешним ориентиром.
- **Статус:** пройдено.

### ORCL — долг и нефискальный год

- **Зачем:** фискальный год к 31 мая; ожидалась высокая долговая нагрузка.
- **Ожидалось:** ряды по концам мая без смешения с календарными; расхождение источников
  долга поднимет флаг; предел множителя не свяжет.
- **Факт:** фискальные ряды чисты — подтверждено. Предел не связал (медиана 27.53) —
  подтверждено. **Флаг долга НЕ поднялся, хотя расхождение было 100%** — дефект, см.
  `DEBT_INCIDENT_REPORT.md`.
- **Отдельно:** ожидание «высокий долг» было предсказанием о компании, а не о поведении
  системы — методическая ошибка составителя, признана.
- **Статус:** пройдено с дефектом.

## 2. Не пройденные имена очереди

| Имя | Архетип | Что проверяет | Статус |
|---|---|---|---|
| LLY | дорогой сектор | предел множителя там, где он кусается; главный аргумент в споре о пределе 30 | не прогонялось |
| SOFI | банк | у банка нет выручки в привычном виде; ожидается деградация слоя и флаги | не прогонялось |
| NVO | иностранный эмитент, IFRS | тест честности отказов, а не данных: теги US-GAAP отсутствуют | не прогонялось |
| RDDT | молодой эмитент | история короче окон; множитель по умолчанию 18 обязан объявляться | не прогонялось |

**Существенно для аудита:** три из четырёх пройденных имён — крупные технологические
компании со схожим профилем. **Выводы о строгости системы опираются на узкую и
однородную выборку.**

## 3. Непокрытые архетипы

Ни одного прогона, ни одной проверки, ни одной строки кода:

| Архетип | Почему опасен | Ожидаемое поведение |
|---|---|---|
| Банк | нет понятия выручки; процентный и комиссионный доход | **гипотеза**: деградация и флаги |
| Страховая | резервы, комбинированный коэффициент | не рассматривалось |
| REIT | FFO вместо прибыли, обязательное распределение | не рассматривалось |
| Циклическая | прибыль на пике цикла даёт ложный темп роста | защиты нет |
| Сырьевая | цена товара определяет всё | не рассматривалось |
| Убыточная растущая | нет положительной базы | уходит на ветку Core-V |
| Крупный SBC | вознаграждение акциями искажает прибыль и поток | SBC в оценку не вычитается |
| Serial acquirer | рост от поглощений выдаётся за органический | защиты нет |
| Отрицательный оборотный капитал | искажение денежного потока | не рассматривалось |
| Иностранный эмитент | IFRS, форма 20-F, коэффициент ADR | ADR не реализован |
| Компания с пересмотром отчётности | старые данные меняются задним числом | понятия нет в коде |
| Несколько классов акций | какой класс считать | частично: в списке помечено вручную |

## 4. Как определялся ожидаемый результат

Ожидания формулировал исполнитель, утверждал архитектор — то есть **обе стороны внутри
одной системы**. Внешней сверки ожиданий не проводилось.

Единственная независимая проверка за историю проекта — совпадение справочной оценки
NFLX с консенсусом аналитиков (менее 1%), и она получена случайно, а не как метод.

**Предложение аудитору:** оценить, можно ли считать валидацией процедуру, где
предсказание, реализация и проверка выполняются одной и той же моделью.

---

## 5. Критерии завершённости матрицы

1. Четыре оставшихся имени прогнаны с пре-регистрацией.
2. По каждому — сверка факта с ожиданием и разбор расхождений.
3. Пересчитан порог качества данных на шести чистых прогонах.
4. Принято решение по пределу множителя на данных семи имён.
5. Закрыт вопрос о капзатратах роста и поддержания.

**Выполнено: ноль из пяти.**
