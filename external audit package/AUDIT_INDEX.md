## 3. Модели и провайдеры

Провайдеры: Anthropic, Google, xAI, поисковая модель, дополнительные вызовы на стадиях
аудита и арбитража.

**Точные идентификаторы моделей в пакете отсутствуют.** Они живут в узлах воркфлоу
и подлежат выгрузке исполнителем — задание выписано, но не выполнено. Приводить их
по памяти запрещено правилом проекта: числа и идентификаторы берутся с выхода
инструментов.

Известно достоверно: стадия xAI **отключена** решением оператора и не исполнялась
как минимум с версии v4.2.44 (проверено по одиннадцати версиям воркфлоу), при этом
её строка печаталась в отчёте о расходах рядом с именем модели двенадцать прогонов
подряд. См. `LLM_GOVERNANCE.md` §3.

## 5. Чего в пакете нет и почему

**Не собирается системой** (то есть отсутствие принципиальное, а не по недосмотру):

- разложение стоимости прогона по шагам, задержки p50/p95, доля отказов, попадания
  в кэш — учёт расходов ведётся, аналитика по стадиям нет;
- хэши промптов;
- «когда каждый тест в последний раз обнаружил реальную ошибку»;
- сырые XBRL-факты в снимках прогонов;
- привязка деревьев версий к коммитам.

**Не написано, но восстановимо** (задания выписаны, работа не выполнена): инвентарь
тестов, схемы вывода, схема базы, назначение каждого из 54 узлов, точные
идентификаторы моделей и параметры вызовов.

**Требует платного прогона:** полные трассы для компаний иных архетипов (банк,
иностранный эмитент). По решению оператора прогоны сейчас не запускаются.

## 6. Исключено из пакета

- позиции портфеля оператора, количества, цены входа, размер капитала — хранятся
  в приватной базе, в публичные репозитории не попадают ни в каком виде;
- ключи API, токены, строки подключения к базе, идентификаторы чатов;
- персональные данные.

Правило зафиксировано в README базы знаний; нарушение влечёт удаление и пересоздание
репозитория, поскольку история публичного репозитория не чистится.

## 7. Утверждения проекта, которые нельзя подтвердить этим пакетом

Перечислены отдельно, потому что это и есть честный ответ на запрос аудита:

1. **«Расчёт воспроизводим»** — арифметика воспроизводима (трасса ORCL, §5), отбор
   фактов — нет: сырьё не сохраняется.
2. **«Система проверена тестами»** — 477 тестов охраняют механику; самый дорогой дефект
   скоринга ими пройден незамеченным и найден человеком при чтении.
3. **«Консилиум нескольких моделей»** — одна из четырёх стадий не исполнялась
   неопределённо долгое время.
4. **«Качественный слой даёт контекст»** — за историю проекта не зафиксировано ни
   одного случая, когда он изменил вывод.
5. **«Гейт расхождения источников работает»** — ветка расхождения не проверена на
   живых данных; сработала запасная.
6. **«Порог качества данных откалиброван»** — калибровка на четырёх наблюдениях,
   метрика с тех пор менялась дважды.

## 8. Что аудитор может сделать прямо сейчас, без нашего участия

1. Скачать дерево версии и запустить сьют: `npm install`, `python run_tests.py`,
   `python tools/mutation_probe.py`.
2. Повторить арифметику ORCL вручную по `TRACE_ORCL.md` §5.
3. Прочитать `ivc_lib.py` целиком — это 331 строка, всё ядро оценки.
4. Сверить `VALUATION_SPEC.md` с кодом и найти расхождения между документом и
   реализацией.
5. Оценить методологические пробелы, перечисленные в `KNOWN_ISSUES.md` раздел D.
