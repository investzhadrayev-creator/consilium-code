## 6. Вердикт и обратный расчёт

**Вердикт: AVOID.** Доходность при текущей цене 10.72% против требуемых 12%.

**Обратный расчёт:** рост, при котором доходность равнялась бы требуемой при текущей
цене, — сравнивается с **фактическим ростом прибыли** (5.21% за 5 лет), а не выручки
(10.72% за 5 лет). Разведение трёх величин сделано после того, как выяснилось, что
сравнение с ростом выручки давало довод против собственного вердикта.

**Одноногий прогон:** `dual_basis = null` — вторая оценка (от денежного потока) не
построилась. Причина: свободный денежный поток на акцию неположителен. В отчёте это
объявлено отдельным абзацем: перекрёстной проверки у этой оценки нет.

## 7. Чего в трассе нет и почему

| Требование аудита | Состояние |
|---|---|
| Номера подач SEC (accession) | частично: провенанс полей сохраняется, но не выводится в артефакт прогона целиком |
| Все использованные XBRL-факты | **не сохраняются** в снимке |
| Контекст, период, единица, тег по каждому факту | **не сохраняются** |
| Правила выбора каждого факта | описаны в `DATA_PIPELINE.md`, но не привязаны к конкретным фактам этого прогона |
| Исходная и нормализованная прибыль раздельно | в артефакте только итоговая нормализованная |
| Долг, денежные средства | есть в машинном отчёте, в расчёт не входят |
| Число разводнённых акций | есть косвенно через `dilution_cagr` |

**Следствие:** независимый аудитор может проверить **арифметику** (§5), но не может
проверить **отбор фактов** — для этого нужен прогон с сохранением сырья.

Это подтверждает вывод `DATA_PIPELINE.md` §3: система не воспроизводима в строгом
смысле. Устранение требует сохранения сырых фактов в снимке — задача не поставлена.
